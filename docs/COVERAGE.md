### Corrections and modern-C notes for L09

- **Slide 7, 9** — The slides write int main(). In C17 an empty parameter list in a definition means 'no parameters', but it is an old-style declaration with no prototype. int main(void) states 'main takes no arguments' explicitly and is one of the two forms the standard lists, so the game uses it. _(taught in `first-contact/anatomy`)_
- **Slide 21, 44, 45, 46, 47** — Several slide examples contain typographic quotes (“ ” instead of "). C only accepts the plain ASCII double quote; copying those lines into a compiler gives errors. All code in the game uses straight quotes. _(taught in `first-contact/beacon-debug`, `sensor-lab/float-scanf`)_
- **Slide 5, 16, 22** — Typos repaired: 'objective files' means object files (slide 5); 'floating-poing' means floating-point (slide 22); ASCII stands for American Standard Code for Information Interchange (slide 16). _(taught in `first-contact/build-pipeline`)_
- **Slide 15** — char is not guaranteed to be exactly 8 bits; the standard requires at least 8 (CHAR_BIT in &lt;limits.h&gt;). On practically every current system it is 8. _(taught in `sensor-lab/type-sizes`)_
- **Slide 18** — The standard guarantees minimum ranges: short and int at least -32767..32767 (16 bits), long at least -2147483647..2147483647 (32 bits), long long (C99) at least 64 bits. Actual sizes are implementation-defined: long is 64 bits on Linux/macOS x86-64 but 32 bits on Windows and in this game's WebAssembly compiler. Use sizeof to check. _(taught in `sensor-lab/type-sizes`)_
- **Slide 37** — 'There is no boolean type in C' was true only of C89. C99 added the type _Bool and the header &lt;stdbool.h&gt; (bool, true, false); C23 makes bool, true and false keywords. Conditions still treat zero as false and non-zero as true. _(taught in `control-center/truth-values`)_
- **Slide 36** — C has no single 'elseif' keyword. 'else if' is simply an else whose statement is another if, which is why chains of else if work. _(taught in `control-center/signum`)_
- **Slide 47** — (++i)+(i++)+(++i) modifies i several times without sequencing. That is undefined behaviour: there is no correct answer, compilers may print anything, and the game never asks you to predict a value for it. _(taught in `supply-depot/forbidden-expression`)_
- **Slide 27** — Strictly, it is the assignment expression (not the statement) that has a value: the value stored in the left operand. _(taught in `supply-depot/assignment-value`)_
- **Slide 43** — switch does not test the cases one after another like MATLAB; it jumps straight to the matching case label. The controlling expression must have integer type (char, int, long ...) and case labels must be integer constants. _(taught in `control-center/machine-modes`)_
- **Slide 31** — 1 + 1.5 converts 1 to double silently (usual arithmetic conversions) without a warning. Warnings appear for possibly lossy conversions, such as double to int, when you enable -Wconversion. _(taught in `supply-depot/type-conversion`)_
- **Slide 28** — The slide's 'Negation:' line lost its symbol; it is the unary minus -x. 'Use your common sense for operator order' is replaced in the game by the actual precedence table. _(taught in `supply-depot/integer-division`)_
- **Slide 11** — gcc file.c works, but prefer gcc -std=c17 -Wall -Wextra file.c -o name: it picks the standard explicitly, turns on helpful warnings and names the executable. _(taught in `first-contact/build-pipeline`)_
- **Slide 4, 8** — Wording clarified: C is usually described as a 'relatively low-level high-level language'. stdio is part of the C standard library defined by the ISO C standard (originally ANSI C). _(taught in `first-contact/wake-up`)_

### Corrections and modern-C notes for L10

- **Slide 8, 9, 10, 11, 12** — The loop examples use typographic quotes (“i=%d\n”). Use plain " in real code. _(taught in `automation-works/for-anatomy`)_
- **Slide 5, 23** — 'Press any key to continue . . .' in the sample output is printed by the IDE (Visual Studio) after the program ends, not by the program. _(taught in `automation-works/digit-sum`)_
- **Slide 9** — a = 2, 3; assigns 2 (assignment binds tighter than the comma); a = (2, 3); assigns 3. Compilers warn that the discarded value is unused: the comma operator is rarely needed outside for headers. _(taught in `automation-works/comma-products`)_
- **Slide 9** — for (i=1, prod=1; i&lt;=n; prod *= i++); has an empty body (the lone ;). It works, but a stray semicolon is a classic bug, so most style guides prefer the third form with an explicit body. _(taught in `automation-works/comma-products`)_
- **Slide 10** — do-while is less common, but it is the natural choice when the body must run at least once, such as asking for input until it is valid. _(taught in `automation-works/do-while-retry`)_
- **Slide 19** — Correct for C99 and later: calling an undeclared function is an error (C89 allowed 'implicit int' declarations). _(taught in `core-systems/times2`)_
- **Slide 20** — With gcc on Linux, programs using &lt;math.h&gt; sometimes need -lm at the end of the command (gcc prog.c -o prog -lm) to link the maths library. _(taught in `core-systems/library-black-boxes`)_
- **Slide 21** — return (2 * x); and return 2 * x; are identical: return is not a function, the parentheses are optional. _(taught in `core-systems/times2`)_
- **Slide 31** — sayHi(1234567) needs int to be wider than 16 bits; the standard only guarantees up to 32767. Use long for IDs that can exceed that on small systems. _(taught in `core-systems/void-functions`)_
- **Slide 30** — In the slide's call distance(1, i, x1, sqrt(y1)+2) inside distance y1 is 2.0 (a double), since the int argument i is converted to the parameter type. _(taught in `core-systems/arguments-and-conversion`)_

### Corrections and modern-C notes for L11

- **Slide 11, 14, 15, 16, 17, 18, 19, 20** — The examples write main() without a return type. 'Implicit int' was removed in C99; in C17 write int main(void) and return 0. _(taught in `data-vault/rack-loops`)_
- **Slide 9** — The slide writes value[1]++ and value[1] += 1, but the array is called values: values[1]++. _(taught in `data-vault/storage-racks`)_
- **Slide 11** — Variable-length arrays (int scores[n];) were added in C99 but are optional since C11 (__STDC_NO_VLA__), cannot be initialised, and can overflow the stack for large n. A #define constant is the portable choice. _(taught in `data-vault/rack-loops`)_
- **Slide 12** — Writing outside an array is undefined behaviour: it may overwrite another variable, crash, or appear to work. The game's compiler adds a runtime check that stops such a program. _(taught in `data-vault/overflow-alarm`)_
- **Slide 17, 18, 19** — Strictly, the array name converts to a pointer to its first element when passed. The function's parameter is that pointer, so sizeof inside the function gives the pointer size, not the array size (clang warns about it). _(taught in `relay-station/clear-banks`)_
- **Slide 33, 35** — gets was not just unsafe: it was removed from the language in C11, so a C17 compiler rejects it. Use fgets(buf, sizeof buf, stdin), and give scanf a width (scanf("%29s", city)). _(taught in `signal-archive/null-terminator`)_
- **Slide 33** — scanf(“%s”, city) uses typographic quotes; real code needs plain " quotes. _(taught in `signal-archive/null-terminator`)_
- **Slide 35** — strlen returns size_t. Since C99 it is printed with %zu; the slide's cast to unsigned with %u also works. _(taught in `text-foundry/length-and-copy`)_
- **Slide 42** — Only the sign of strcmp's result is defined. The slide's -1 is what some libraries return; others return the difference of the characters (for example -6). Compare the result with 0, never with -1 or 1. _(taught in `text-foundry/join-and-compare`)_
- **Slide 43** — pch - str has type ptrdiff_t, so printing it with %d is not portable. Use %td or convert it: (int)(pch - str). The prototype on the slide also lacks the parameter name str. _(taught in `text-foundry/search`)_
- **Slide 45** — atoi and atof cannot report errors: atoi("abc") is 0 and atoi("12abc") is 12. strtol and strtod (also in &lt;stdlib.h&gt;) report where the number ended. _(taught in `text-foundry/numbers-from-text`)_
